SPORTZONE

Описание проекта

SPORTZONE — мобильное приложение спортивного магазина.

Основные страницы приложения

1. Home — главная страница.
2. Shop — каталог спортивных товаров.
3. Product details — подробная информация о товаре.
4. My Cart — корзина покупателя.

Основные возможности

- Просмотр спортивных товаров.
- Поиск товаров.
- Просмотр карточек товаров.
- Выбор размера и цвета.
- Добавление товаров в корзину.
- Просмотр содержимого корзины.

Дизайн

Макет мобильного приложения разработан в Figma.
